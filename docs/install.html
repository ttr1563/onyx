Installation

Choose a verified path.

Signed Linux repositories are the operational default. Homebrew and tag-pinned source installation are available when a native package is not.

Support matrix

EnvironmentInstall pathProtection scope
Amazon Linux 2023 x86_64Signed DNF repositorySupported Linux target
Debian 12 / Ubuntu 22.04+ amd64Signed APT repositorySupported Linux target
Other LinuxHomebrew or release-tag Cargo installBuildable; distribution verification varies
macOSHomebrew or CargoBuild path only; native command protection is unverified

Every platform keeps the same boundary: only commands explicitly launched through onyx run -- ... are evaluated.

Amazon Linux 2023

sudo rpm --import https://ttr1563.github.io/onyx/rpm/RPM-GPG-KEY-ONYX
sudo dnf install https://ttr1563.github.io/onyx/rpm/onyx-release-1-1.noarch.rpm
sudo dnf install onyx

Expected key fingerprint: E9E3 C123 DEDF B3E9 AEA1 F3A9 CD2E 615D BC32 CF0C. Upgrade with sudo dnf upgrade onyx.

Debian 12 and Ubuntu 22.04 or later

Download the key as a regular user, inspect its fingerprint, and only then install the key and scoped deb822 source:

curl -fsSLO https://ttr1563.github.io/onyx/apt/onyx.asc
gpg --show-keys --with-fingerprint onyx.asc
# Expected: E9E3 C123 DEDF B3E9 AEA1 F3A9 CD2E 615D BC32 CF0C
sudo install -D -m0644 onyx.asc /etc/apt/keyrings/onyx.asc

curl -fsSLO https://ttr1563.github.io/onyx/apt/onyx.sources
sudo install -m0644 onyx.sources /etc/apt/sources.list.d/onyx.sources
rm onyx.asc onyx.sources

sudo apt-get update
sudo apt-get install onyx

Upgrade with sudo apt-get update && sudo apt-get install --only-upgrade onyx. The source file uses Signed-By; the key does not become a global APT trust anchor.

Homebrew

brew tap ttr1563/onyx https://github.com/ttr1563/onyx.git
brew install ttr1563/onyx/onyx

Linux is the verified protection target. The formula can build on macOS, but native macOS command protection is not claimed.

Install from Git

Use an immutable release tag and the committed lockfile:

cargo install \
  --git https://github.com/ttr1563/onyx.git \
  --tag v0.1.3 \
  --locked

Rust 1.91 or later and a platform C toolchain are required. For development, clone the same tag and run cargo install --path . --locked. Do not use a mutable branch for repeatable server deployment.

Windows x64 through WSL 2

Open PowerShell as Administrator, install WSL, and restart when prompted:

wsl --install

Open the Ubuntu terminal and use the APT procedure above. Initialize and run Onyx inside that Linux terminal. See Microsoft's WSL installation guide for version requirements. Native Windows processes, PowerShell, Command Prompt, and Windows services are not supported.

Verify and remove

onyx --version
onyx check -- rm -rf /example
# Expected: blocked result and exit code 77

Use sudo dnf remove onyx, sudo apt-get remove onyx, or cargo uninstall onyx-guard for the matching install path. Package removal deliberately leaves /var/lib/onyx execution state and /etc/onyx policy, administrator authentication state, and audit evidence. Review retention and incident requirements before deleting either path separately.
