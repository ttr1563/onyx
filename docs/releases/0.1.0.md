# Onyx v0.1.0

Onyx v0.1.0 is the first development release of the explicit Linux command guard.

## Highlights

- blocks a small, auditable set of dangerous command patterns before execution;
- binds a 30-second, one-use permit to the exact command after TOTP approval;
- records redacted evidence as local JSON Lines without cloud credentials;
- rejects unsafe state ownership, permissions, symbolic links, non-regular files, and oversized state;
- supports additive site-specific rules;
- includes Homebrew and source installation paths plus an operations runbook.

## Install with Homebrew

```console
brew tap ttr1563/onyx https://github.com/ttr1563/onyx.git
brew install ttr1563/onyx/onyx
```

## Important boundary

This release protects only commands launched through `onyx run -- ...`. It is not host-wide enforcement. The state owner can read the TOTP seed, root can bypass the wrapper, and privileged access can alter local logs. Review [SECURITY.md](https://github.com/ttr1563/onyx/blob/v0.1.0/SECURITY.md) before production use.
