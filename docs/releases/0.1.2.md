# Onyx v0.1.2

Onyx v0.1.2 adds a signed APT repository, tag-pinned Cargo installation, and
complete English/Japanese installation guidance. Command evaluation and the
explicit-wrapper security boundary are unchanged from v0.1.1.

## Debian and Ubuntu installation

Download the dedicated repository key, verify fingerprint
`E9E3 C123 DEDF B3E9 AEA1 F3A9 CD2E 615D BC32 CF0C`, install the published
deb822 source, and then use APT:

```console
sudo apt-get update
sudo apt-get install onyx
```

The initial repository supports `amd64` on Debian 12 and Ubuntu 22.04 or later.
Repository metadata is signed and the source uses `Signed-By` to scope trust to
the Onyx key.

## Windows boundary

Windows x64 users can install Onyx inside WSL 2 and then follow the Ubuntu APT
instructions. The published package is `amd64`. Onyx protects only Linux commands explicitly launched through
`onyx run` inside WSL. It does not protect PowerShell, Command Prompt, native
Windows processes, or Windows services.

## Other changes

- `cargo install --git ... --tag v0.1.2 --locked` provides a tag-pinned source path.
- English and Japanese installation pages explain prerequisites, updates,
  removal, state retention, and platform support.
- The APT runbook documents deterministic packaging, signing, verification,
  rollback, compatibility testing, and shared package-key rotation.

## Security boundary

Onyx remains an explicit Linux command wrapper. Root and the operating-system
identity that owns writable Onyx state remain outside the v0.1 security
boundary. Review `SECURITY.md` before production use.
