# Onyx v0.1.1

Onyx v0.1.1 adds a signed Amazon Linux 2023 package repository and a Japanese
version of the project site. The command guard behavior and its explicit-wrapper
security boundary are unchanged from v0.1.0.

## Amazon Linux 2023 installation

```console
sudo rpm --import https://ttr1563.github.io/onyx/rpm/RPM-GPG-KEY-ONYX
sudo dnf install https://ttr1563.github.io/onyx/rpm/onyx-release-1-1.noarch.rpm
sudo dnf install onyx
```

The initial repository supports `x86_64`. Verify the signing key before import:

```text
E9E3 C123 DEDF B3E9 AEA1 F3A9 CD2E 615D BC32 CF0C
```

SHA-256 checksums are published with the final GitHub Release artifacts.

## Other changes

- DNF metadata and package signature verification are enabled by default.
- Package removal retains `/var/lib/onyx` authentication state and audit logs.
- GitHub Pages is available in English at `/` and Japanese at `/ja/`.
- The package repository runbook documents publication, rollback, and key rotation.

## Security boundary

Onyx still protects only commands launched with `onyx run -- ...`. Root and the
operating-system identity that owns writable Onyx state remain outside the v0.1
security boundary. Review `SECURITY.md` before production use.
