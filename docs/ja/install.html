導入

検証済みの経路を選ぶ。

運用環境では署名付きLinuxリポジトリを基本とし、native packageがない環境ではHomebrewまたは固定したrelease tagを利用します。

対応表

環境導入方法保護範囲
Amazon Linux 2023 x86_64署名付きDNF repository対応済みLinux target
Debian 12 / Ubuntu 22.04以降 amd64署名付きAPT repository対応済みLinux target
その他のLinuxHomebrewまたはrelease tag指定Cargobuild可能、distributionごとの検証状況は異なる
macOSHomebrewまたはCargobuild経路のみ。macOS native保護は未検証
Windows 10/11 x64WSL 2導入後にLinux手順WSL内のみ。PowerShellとWindows processは対象外

全環境で共通の境界：onyx run -- ...から明示的に起動したコマンドだけを判定します。

Amazon Linux 2023

sudo rpm --import https://ttr1563.github.io/onyx/rpm/RPM-GPG-KEY-ONYX
sudo dnf install https://ttr1563.github.io/onyx/rpm/onyx-release-1-1.noarch.rpm
sudo dnf install onyx

想定fingerprintはE9E3 C123 DEDF B3E9 AEA1 F3A9 CD2E 615D BC32 CF0Cです。更新はsudo dnf upgrade onyxです。

Debian 12・Ubuntu 22.04以降

一般ユーザーで公開鍵を取得してfingerprintを確認した後、鍵と適用範囲を限定したdeb822 sourceを配置します。

curl -fsSLO https://ttr1563.github.io/onyx/apt/onyx.asc
gpg --show-keys --with-fingerprint onyx.asc
# Expected: E9E3 C123 DEDF B3E9 AEA1 F3A9 CD2E 615D BC32 CF0C
sudo install -D -m0644 onyx.asc /etc/apt/keyrings/onyx.asc

curl -fsSLO https://ttr1563.github.io/onyx/apt/onyx.sources
sudo install -m0644 onyx.sources /etc/apt/sources.list.d/onyx.sources
rm onyx.asc onyx.sources

sudo apt-get update
sudo apt-get install onyx

更新はsudo apt-get update && sudo apt-get install --only-upgrade onyxです。sourceのSigned-Byにより、公開鍵をAPT全体のtrust anchorにはしません。

Homebrew

brew tap ttr1563/onyx https://github.com/ttr1563/onyx.git
brew install ttr1563/onyx/onyx

検証済みの保護対象はLinuxです。FormulaはmacOSでbuild可能な想定ですが、macOS nativeのコマンド保護は現行版の対応範囲ではありません。

Gitから導入

変更されないrelease tagとlockfileを指定します。

cargo install \
  --git https://github.com/ttr1563/onyx.git \
  --tag v0.1.2 \
  --locked

Rust 1.91以降とplatformのC toolchainが必要です。開発時は同じtagをcloneし、cargo install --path . --lockedを実行します。再現可能なserver導入に可変branchは使用しません。

Windows x64はWSL 2経由

管理者PowerShellでWSLを導入し、求められた場合は再起動します。

wsl --install

導入されたUbuntu terminalを開き、上記APT手順を実行します。Onyxの初期化と保護対象commandもLinux terminal内で実行してください。version要件はMicrosoftのWSL導入ガイドを参照してください。PowerShell、Command Prompt、Windows service、WSL外のnative .exeは対象外です。

確認と削除

onyx --version
onyx check -- rm -rf /example
# 想定結果: 遮断され、終了コード77

導入経路に応じてsudo dnf remove onyx、sudo apt-get remove onyx、またはcargo uninstall onyx-guardを使います。package削除後も/var/lib/onyxの実行状態と、/etc/onyxのpolicy・管理認証状態・監査証跡は意図的に残します。保持・incident要件を確認してから、必要な場合だけ別操作で削除してください。
